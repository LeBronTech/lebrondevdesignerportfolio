## 📌 Sobre o Projeto

Este repositório contém o código-fonte do portfólio profissional de **Leandro José**. Desenvolvido com uma arquitetura moderna e componentizada em **React 19**, **TypeScript** e **Vite 6**, o website foi planejado para oferecer máxima fluidez visual, performance instantânea e navegação responsiva em qualquer dispositivo (Desktop, Tablet e Mobile).

- **🗂️ Portfólio Interativo & Filtrável**: Navegação intuitiva por categorias (**Todos**, **Websites**, **Apps**, **Identidade Visual**, **Product**, **Logos**).
- **🔍 Modal de Detalhes Completo**: Carrosséis de alta definição com zoom, visualização passo a passo do processo criativo, papel desempenhado, metodologia e links diretos para projetos em produção, repositórios no GitHub e Behance.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- **Node.js** (versão 18.x ou superior recomendada)
- **npm** ou **yarn** / **pnpm**

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/portfolio-leandro-jose.git
   cd portfolio-leandro-jose
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse a aplicação em [http://localhost:3000](http://localhost:3000) (ou na porta configurada pelo Vite).

4. **Gerar a build de produção:**
   ```bash
   npm run build
   ```

5. **Visualizar a build localmente:**
   ```bash
   npm run preview
   ```
